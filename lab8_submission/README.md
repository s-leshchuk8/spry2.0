# Lab 8 supplementary submission files for spry2.0

These files are ADDITIONS, not a full clone of the existing Spry repository. Copy the contents into a `lab8/` directory inside the cloned repository. The existing root producer.py and consumer.py are intentionally untouched.

Start with REPORT_AND_ANSWERS.md. Replace `YOUR_BUCKET`, run SQL statements individually, replay one source-day JSONL, capture experiment outputs, then provision the cloud pipeline and clean it up. Evidence images supplied by the user are in evidence/. Do not claim this package alone completes cloud deployments or experiments.
